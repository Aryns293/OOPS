# Q41 SOLID Principles

**Interview Answer:**
S – Single Responsibility: A class should have only one reason to change.
O – Open/Closed: Open for extension, closed for modification.
L – Liskov Substitution: Subtypes must be usable in place of base types.
I – Interface Segregation: Many small interfaces > one large interface.
D – Dependency Inversion: Depend on abstractions, not concrete implementations.

Summary: SOLID leads to maintainable, flexible, testable code.
