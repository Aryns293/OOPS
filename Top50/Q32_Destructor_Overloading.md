# Q32 Destructor Overloading

**Interview Answer:**
Destructor overloading: No. A destructor has no parameters and no return type, so it cannot be overloaded. A class can have only one destructor.

Constructor static: No. Constructors are called on objects, and static means class-level without an object. Also, constructors cannot be virtual or static.

Summary: Destructor: only one per class. Constructor: cannot be static.
