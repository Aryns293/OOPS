# Q01 What is OOP?

## 🎯 Interview Answer
**Object-Oriented Programming (OOP)** is a programming paradigm that organizes software design around **objects** rather than functions and logic. An object is an instance of a class that bundles **data** (attributes) and **behavior** (methods) into a single cohesive unit.

OOP solves the main problem of procedural programming—where global data is accessible from anywhere, leading to unintended modifications, namespace pollution, and hard-to-maintain code. OOP protects data inside objects and provides clear boundaries.

---

## ❓ Why do we need OOP?

### 🧩 Core Benefits
- **Modularity:** Code is organized into self-contained objects, making it easier to manage and debug.
- **Reusability:** Through inheritance, we can reuse existing code without rewriting it.
- **Security:** Through encapsulation, data is hidden and can only be accessed through controlled public methods.
- **Maintainability:** Changes in one object don’t ripple everywhere, so code is easier to update and extend.
- **Real-world modeling:** Objects map directly to real-world entities (e.g., `Student`, `Account`, `Car`).
- **Flexibility and scalability:** Through abstraction and polymorphism, we can design flexible and extensible systems.

---

## 🎯 Summary to Impress
- **The Core formula:** OOP = Objects + Classes + Encapsulation + Abstraction + Inheritance + Polymorphism.
- **Procedural problem:** Global data → unintended changes → bugs.
- **OOP solution:** Data hiding + controlled access + clear structure.
